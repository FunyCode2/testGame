# 💻 Programación Orientada a Objetos (POO)

> _Aprendiendo a diseñar software mediante objetos y buenas prácticas de programación._

Bienvenido a este repositorio, un espacio dedicado a la práctica y exploración de la **Programación Orientada a Objetos (POO)**. Aquí encontrarás ejercicios, ejemplos y proyectos orientados a comprender y aplicar los principios fundamentales de este paradigma, fortaleciendo habilidades en el diseño y desarrollo de software.

A lo largo del repositorio se abordarán conceptos como:

- 📦 Clases y objetos
- 🔒 Encapsulamiento
- 🧬 Herencia
- 🔄 Polimorfismo
- 🎯 Abstracción
- 🛠️ Métodos y atributos

Cada sección refleja el proceso de aprendizaje y la aplicación práctica de estos conceptos mediante diferentes ejercicios y actividades.
